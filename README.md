# KalmanFilters_H-Infinity_LQG
This repository includes solutions involving LQG control design, H∞ robust controller synthesis, and uncertainty analysis using polytopic and random sampling methods. It features MATLAB code, simulations, and plots illustrating system performance and robustness.
